# Project: JALIMCORP Digital Business Card Pages

## Purpose
This project contains mobile-first employee contact pages used for QR codes on business cards.

Each page should function as a premium digital business card that allows users to:
- Contact the employee via email
- Message via WhatsApp
- Visit LinkedIn
- View employee photo
- Recognize company branding

## Design Principles
- Mobile-first design (primary use case: QR scan on phone)
- Clean, minimal, premium corporate aesthetic
- Dark theme preferred
- Strong spacing and alignment
- High contrast for readability
- Fast loading, lightweight pages

## UI/UX Guidelines
- Large, bold employee name at the top
- Clear job title
- Prominent, tap-friendly contact buttons (Email, WhatsApp, LinkedIn)
- Icons must be clean and consistent
- Portrait image should be well-presented (centered, possibly rounded)
- Company logo should be visible but not overpowering
- Sections should be clearly separated with spacing or dividers

## Code Requirements
- Use semantic HTML
- Keep CSS clean and maintainable
- Avoid heavy frameworks
- Optimize for GitHub Pages hosting
- Ensure responsiveness across screen sizes
- Maintain accessibility (alt text, contrast, etc.)

## Reusability
- Structure code so new employee pages can be created easily
- Prefer reusable layouts and components
- Keep employee-specific data easy to replace

## Improvements Focus
When modifying this project, prioritize:
- Visual polish
- Simplicity
- Consistency across pages
- Performance
- Professional appearance

## What to Avoid
- Overly complex designs
- Heavy animations
- Large dependencies
- Cluttered layouts

## Output Expectations
When making changes:
- Explain what was changed and why
- Suggest improvements
- Keep code clean and readable

## Branding

### Brand Identity
- Company: JALIMCORP
- Tone: Professional, modern, premium, corporate

### Colour Palette
The JALIMCORP brand uses a minimal, high-contrast palette inspired by the company logo:

- Black: Primary background colour
- White: Primary text colour
- Red: Accent colour for highlights, buttons, and key interactions
- Grey: Secondary text, dividers, and subtle UI elements

### Colour Usage Guidelines
- Use black as the dominant background for a clean, premium feel
- Use white for main text to ensure strong readability
- Use red sparingly for:
  - Call-to-action buttons (e.g. WhatsApp, Email)
  - Hover/tap states
  - Important highlights
- Use grey for:
  - Section dividers
  - Secondary text (e.g. job title)
  - Subtle UI separation

### Logo Usage
- Always include the JALIMCORP logo on each page
- Position it in a clean, non-intrusive area (top or bottom)
- Maintain proper spacing around the logo
- Do not distort or stretch the logo

### Visual Style
- Minimal and uncluttered
- Strong alignment and spacing
- Subtle separators instead of heavy borders
- Premium, understated look rather than flashy design

### Suggested Colour Values
- Black: #000000
- White: #FFFFFF
- Red: #E10600 (or similar bold red)
- Grey: #888888 (adjust for contrast where needed)
